It resolves Cargo through rustup in the repository and prepends that toolchain's bin directory, then executes Cargo directly while preserving the caller's working directory. Ordinary developer overrides remain available; the qualification mode rejects compiler/bootstrap/wrapper substitutions from the environment or Cargo configuration and requires exact rustc release 1.99.1. The policy parser structurally reads TOML through `tomllib`, `tomli`, or `pip._vendor.tomli`; it installs nothing. Actual system Python 3.9 passed the policy probe, 16 toolchain tests and 23 workflow tests; the full Python suite passed 98 tests.

On macOS SIP can strip incoming DYLD variables before a protected shell starts; `ABBEY_DYLD_FALLBACK_LIBRARY_PATH` carries an explicit custom fallback through that boundary and nested ABI scripts. No libraries are copied and no global environment is changed. Existing explicit CC/CXX remain intact; otherwise system compilers take precedence.
